# Decision prompts from the 1901 rules

Use these as a checklist when composing a palette or writing a prompt.
Each prompt traces to a rule in `art_01M6QE3AFSCKYM2GFJG7K5J962` rev 2.

---

## Rule I — Bold use only
**Prompt:** Am I using both colors of the pair at full spectral purity in
balanced quantities?
- If YES → this is a bold or focal choice. The source says soften it
  with tints or shades, especially in a picture.
- If NO → proceed to the other rules.

## Rule II — Quantity alone does not resolve contrast
**Prompt:** Have I changed *quality* (purity) as well as *quantity*?
- Equal portions of two pure spectral complements stay in tension.
  Harmony requires a change in one or both dimensions.

## Rule III — Neutralize to add more
**Prompt:** Which color of the pair is more neutral (tinted or shaded)?
- The more neutral one may occupy more area.
- Example in source: small bright spectral red against large pale blue-green.

## Rule IV — Mix tints and shades within one color
**Prompt:** Am I using only one value of each color?
- Using two or more tints of one complement, or combining tints with
  shades of it, gives a "finer" harmony (source word).

## Rule VI — Full harmony structure
**Prompt:** Does my palette include tints, shades, AND a small accent
of the pure spectral tone for each color of the pair?
- Largest area: lightest/most neutral (Rule III applies).
- Smallest area: darkest or most saturated.
- Small spectral accent present in both colors.

## Rule VII — Small portions exempt Rule I
**Prompt:** Am I using pure spectral complements only in small,
repeating portions (e.g., a pattern unit)?
- If YES → the source says this can work "with good effect".
  Example given: diaper patterns.

## Blue-and-yellow note (undated, from same section)
Blue and yellow are described as "used with great success"; the source
attributes this to yellow being "so much more luminous (or lighter)",
producing "a greater contrast" that is "more agreeable".
This is a period claim, not a tested result.
