# Blinding and presentation protocol

Strip method notes and variant labels before presenting to readers.
Present all three passages in a randomised order per reader.
Assign each passage a neutral code (P1, P2, P3) drawn fresh per session.

## Task 1 — Type sort
Ask: "One of these passages describes an ordinary, everyday event.
Which one is it?" Record the code the reader names.
Chance baseline: 33 %.

## Task 2 — Method sort (bizarre passages only)
Reveal that two passages share the same strange premise but were
written in different ways. Ask: "Which passage felt more grounded in
familiar, everyday detail? Which felt more like a camera held steady
on strange facts?" Record which code they assign to each description.
Chance baseline: 50 %.

## Confound checks (record for each session)
- Word count per passage (target ≤ ± 5 words of 110)
- Sentence count per passage (target ≤ ± 1 of 9)
- Proper nouns present (A: yes; B and C: none — flag if noticed)

Note: Proper nouns in A (mother, corduroy, March) are part of the
familiar-anchoring method and cannot be removed without changing the
treatment. Record whether readers mention them; treat as a secondary
observation, not a confound to fix.
