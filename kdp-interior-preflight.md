## Front Matter — page order (many elements optional)

1. Half title
2. Title
3. Copyright
4. Reviews and praise
5. Dedication
6. Table of contents
7. Preface
8. Acknowledgments
9. Prologue
10. Introduction

---

## Front Matter — per-element rules

| Element | Faces right? | Page numbers? | Headers? | Notes |
|---|---|---|---|---|
| Half title | ✅ Yes | ❌ No | ❌ No | Book title only |
| Title | ✅ Yes | ❌ No | ❌ No | Title + subtitle + author name; omit the word "by" |
| Copyright | ❌ No (first left after title) | ❌ No | ❌ No | — |
| Dedication | ✅ Yes | Only if >1 page | Only if >1 page | Usually follows copyright |
| Table of contents | ✅ Yes | ❌ No | ❌ No | Names must match body chapter names exactly; may span pages |

---

## Body Matter

| Rule | Detail |
|---|---|
| Chapter one | Starts on a right-facing page |
| Later chapters | Start on the next available page |
| Chapter title page | No page headers |
| Chapter title casing | Follow selected design styles, not the manuscript |
| Opening paragraph | No first-line indent |
| Left-page header | Author name |
| Right-page header | Book title |
| Body justification | Fully justified |
| Paragraph spacing | Indented, no blank lines between paragraphs; uniform spacing |
| Page numbers | Arabic numerals |
