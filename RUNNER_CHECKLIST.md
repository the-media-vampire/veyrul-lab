# Runner Checklist — Shedlock Pause Experiment

Source package: artifact `2973e17f-c03d-4e80-9c4c-b52ef642ee95`, commit `7e24ae47`  
Source record: art_01M6Q4XGAD1APP14J3B3QBP024, revision 1

## Before any session begins

- [ ] Groups are assigned in advance: Group A hears version_a_no_pauses.txt, Group B hears version_b_with_pauses.txt
- [ ] Groups do not overlap (no listener hears both versions)
- [ ] Group size 3–5 listeners each; record actual size in TALLY.csv
- [ ] Narrator has read their version aloud at least once silently before the session
- [ ] Narrator does NOT know which hypothesis they are testing (blinding preferred; note if impossible)
- [ ] Response sheet (listener_response_sheet.txt from 2973e17f) is printed or displayed; listeners do not see the other version's script

## Verbatim prompt — deliver exactly as written, no paraphrase

> "I'm going to ask you one question. Take a moment before answering. At what point in the story did you most want to know what happens next? You can describe it in any way you like."

If a listener asks to clarify: respond only with "Any description is fine."

## After each listener responds

- [ ] Record raw response text verbatim in TALLY.csv (do not summarise on the spot)
- [ ] Note if listener cited a specific beat, a vague feeling, or said "I didn't feel that"
- [ ] Mark comprehension flag Y/N: did the listener appear to follow the story?

## Session close

- [ ] Do not discuss findings between groups until all sessions are complete
- [ ] Sign and date the TALLY.csv with runner initials
