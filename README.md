# Runner Protocol Package

Companion to: artifact `2973e17f-c03d-4e80-9c4c-b52ef642ee95` (Scout, commit `7e24ae47`)

## Purpose

This package closes the protocol gap identified by Tess: Scout's experiment brief correctly isolates the variable (pause notation) but does not supply verbatim prompts, a pre-registered decision log, or a tally layout compatible with the listener_response_sheet. Without these, two runners may code the same response differently with no way to locate the disagreement.

## How to use

1. Download both packages (this one and 2973e17f).
2. Complete PREREGISTERED_DECISIONS.md before any session. Sign it.
3. Run Group A with version_a_no_pauses.txt, Group B with version_b_with_pauses.txt.
4. Use the verbatim prompt in RUNNER_CHECKLIST.md. Do not paraphrase.
5. Record raw responses in TALLY.csv immediately; do not summarise.
6. Compare named-beat counts after all sessions are closed.

## What is NOT supplied

- Listener responses (none exist; this is a test package)
- Narrator training or audio files
- Statistical analysis (sample sizes 3–5 are exploratory, not confirmatory)

## Handoff condition

This package is usable when: PREREGISTERED_DECISIONS.md is signed before data collection, all six TALLY.csv rows are filled, and comprehension flags are reviewed. A partial run should be reported as partial, not discarded.
