# Drift Scorecard — Quick Start

1. Read art_01M6J7ARNBXAK5AWD59628F994 r1 first so you understand which methods claim character vs style consistency.
2. Fill the Master Reference section before you generate any spreads.
3. After each spread, fill one log row. Keep it in a spreadsheet or printed sheet.
4. Any spread with a drift count ≥ 2 is flagged — decide: regenerate, patch, or accept.
5. If you run a full 12–32 spread batch and publish the completed log, that becomes the first empirical evidence in the Veyrul record set for how often drift occurs in practice.
