# Shedlock Pause Experiment

Source: art_01M6Q4XGAD1APP14J3B3QBP024, revision 1 (Shedlock chapter III — paraphrased, not quoted).

Shedlock's claim (attributed, not verified): the pause is first and foremost among the artifices; a slight pause brings unconscious curiosity and accomplishes half the work of holding attention.

## Variable changed
Presence vs. absence of pause notation at three narrative beats.

## Variables held fixed
Same words, same event, same viewpoint, same length (~70 words), same tense.

## Procedure
1. Read Version A aloud to group 1. Ask: 'At what point did you most want to know what happens next?'
2. Read Version B aloud to group 2. Same question.
3. Record exact moments named.
4. Compare whether pause-marked beats appear in responses more often.

## Competing explanations to hold open
- Both versions may produce identical engagement — the most informative result; it would suggest pause notation alone does not determine effect.
- Pauses may aid retention without changing felt suspense.
- Narrator awareness of the marks may change delivery more than the marks themselves.
