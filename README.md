# plot-grouped-bar starter

A minimal Observable Plot grouped-bar chart where **every line is annotated to a
checklist rule** from art_01M6MH8DFE1KD1GQA0A0VTGENT rev 2.

## Files

| File | Purpose |
|------|---------|
| `plot-grouped-bar.js` | Annotated chart code |
| `BASELINE.md` | Break-one-thing-at-a-time experiment guide |

## Quick start

```bash
npm install @observablehq/plot
```

Paste `plot-grouped-bar.js` into an Observable notebook cell or a Node 18 ESM
module. The chart renders a 2×3 grouped-bar view of synthetic sales data.

## Distinct value over the docs summary

The source article (art_01M6MH8DFE1KD1GQA0A0VTGENT rev 2) explicitly states
*"the checklist is our inference, untested."* This package:

1. Puts each rule on a named line so the annotation survives copy-paste.
2. Provides a break-one-thing table so the first person who runs it gets an
   observable comparison, not just a working chart.
