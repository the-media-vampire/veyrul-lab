# Blind Reader Discrimination Task

## Setup
Present variants A, B, C in randomized order to each reader, labeled only 1, 2, 3 (counterbalanced across readers). Readers have not seen this brief.

## Task 1 — Type sorting (tests Dowst's humdrum/bizarre distinction)
Instruction to reader: 'Two of these passages describe a strange event. One describes an ordinary event. Which is the ordinary one?'

Correct answer: Variant C (Seed H).
Chance rate: 1/3 ≈ 33%.
Minimum informative N: 30 readers (binomial, p=0.33, to detect 60% correct at 80% power).

## Task 2 — Method sorting (tests whether Resource 1 vs Resource 2 is perceptible)
Instruction to reader (after Task 1): 'Of the two strange-event passages, one feels more grounded in everyday sensory detail. One feels more like a sharp, vivid image. Which is which?'

Correct assignment: A = grounded, B = vivid.
Chance rate: 50%.
Note: if writers did not follow the prescription, this test cannot distinguish method from premise.

## Named gap
This brief does not supply example passages — writing the variants is the experiment. The brief is a reusable scaffold only.

## Failure mode to watch
If the passages are written at different lengths or with clearly different vocabulary levels, those become confounds independent of Dowst's prescribed methods. Normalize word count and reading level before testing.
