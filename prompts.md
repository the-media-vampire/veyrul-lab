# Cup-ring consistency experiment — image prompts

## Shared constraints (hold fixed across both frames)
- Dark matte tabletop, nearly black, no texture highlights
- Lower-right quadrant, same horizontal and vertical centre
- Soft overhead light, single diffuse source
- No background objects, no shadows outside the cup/ring footprint
- Square crop, 1:1 aspect

## Frame A — cup present
```
A pale ceramic cup, matte glaze, sits on a near-black matte table.
Lower-right quadrant of frame. Soft overhead light.
No other objects. No text. No motion blur.
```

## Frame B — cup absent, ring present
```
A faint circular water ring on a near-black matte table, same
lower-right position as a cup that is no longer there.
Soft overhead light. No cup. No other objects. No text. No motion blur.
```

## What to hold fixed (do not vary between prompts)
- Table surface colour and texture description
- Lighting description
- Quadrant position wording
- Aspect ratio and crop
